# Purpose

This document provides a complete inventory of all planned features for Acadedx.

It serves as the master feature catalog for Product Managers, Designers, Engineers, QA Engineers, AI Engineers, and Business Stakeholders.

Each feature has a unique identifier, priority, release phase, dependencies, and implementation status.

---

# Feature Status

| Status | Meaning |
|---------|----------|
| Planned | Not yet started |
| In Design | UI/UX in progress |
| In Development | Engineering started |
| Testing | QA testing |
| Released | Available to users |
| Deprecated | Removed |
